# Odin1 深度轮足 8000 轮课程

目标是先建立稳定低速控制，再学习带深度感知的地形通过，后期开放更高台阶、更陡坡面和更密集障碍。策略维持 780 维输入、16 维输出，速度最终覆盖 x/y ±0.6 m/s、偏航 ±1 rad/s，姿态最终覆盖 pitch/roll ±10°、高度 ±7 cm。

配置入口为 `rp_wd_odin_depth_env_cfg.py`，训练入口为 `train_odin_depth.sh`。默认 256 个环境、8000 次 PPO 更新、每次更新 24 个策略步，所有时间表按这个 rollout 长度设计。

## 地形阶段

| 迭代范围 | 可用最高地形等级 | 目标 |
|---|---:|---|
| 0–999 | 1 / 11 | 小台阶、缓坡和稀疏低箱体，先稳定站立与低速行进 |
| 1000–2499 | 3 / 11 | 扩展移动方向与速度，学习基础地形几何 |
| 2500–4499 | 5 / 11 | 完整速度范围、感知扰动和逐步扩展的姿态目标 |
| 4500–5999 | 8 / 11 | 增加台阶、坡度、粗糙度与箱体密度 |
| 6000–7999 | 11 / 11 | 开放全部挑战，在完整推扰、感知扰动与力矩约束下巩固 |

每个环境从第 0 级出生。走出半个地块（3 m）才升级，未完成预期距离的一半会降级；表格规定的是最高可用难度。能力不足的机器人会留在较低等级继续学习。

地形生成 12 行 × 12 列，七类地形都有采样列。以下范围随地形行的 difficulty 变化：

| 地形 | 简单端 → 困难端 |
|---|---|
| 上/下台阶 | 1 → 12 cm，阶宽 40 cm |
| 随机方格 | 高差 1 → 10 cm |
| 坡面 | 坡度比 0 → 0.40（约 22°） |
| 平滑随机粗糙 | 振幅 ±0.5 → ±5.5 cm，30 cm 空间采样后平滑 |
| 随机箱体 | 1 → 8 个；可见高度约 4 → 22 cm，尺寸 25×25 → 65×55 cm |

高箱体主要用于学习绕行，台阶用于学习通过；最高几何难度是训练目标，尚无通过率结论。官方 uniform 随机高度场本身忽略 difficulty，本任务用 wrapper 显式缩放粗糙幅度。

## 同步增加的任务与扰动

| 项目 | 时间表 |
|---|---|
| 速度范围 | 前 100 轮为完整范围的 20%；100–2400 轮线性扩大至 x/y ±0.6 m/s、wz ±1 rad/s |
| 深度增强 | 前 500 轮清晰深度；500–2500 轮渐入 0.03 m 高斯噪声、1% 像素缺测与 80–100% 随机裁切 |
| 姿态/高度 | 前 1500 轮目标为零；1500–4000 轮线性放大至 pitch/roll ±10°、高度 ±7 cm |
| 周期推扰 | 前 1200 轮不推；1200–5000 轮渐增至原有 x/y/z 速度扰动幅度 0.6/0.4/0.2 m/s，间隔 8–12 s |
| 腿部力矩惩罚 | 前 5600 轮权重为零；5600–6800 轮逐级增加至 -1e-5；最后 1200 轮稳定巩固 |

摩擦、质量、质心、执行器增益、关节参数与传感器偏置随机化沿用原 rough 配置。训练观察 `Curriculum/terrain_levels`、`command_lin_vel`、`posture_command`、`push_curriculum` 和 `leg_torque_penalty`；同时检查跟踪误差、回合长度和真实终止率，不能只根据平均回报判断能否通过地形。

## 启动与续训

```bash
# 新训练，8000 轮总目标
./rl/scripts/train_odin_depth.sh --run_name odin1_curriculum8k

# 从当前实验最近 checkpoint 继续，到总目标 8000
./rl/scripts/train_odin_depth.sh --resume --max_iterations 8000 --run_name odin1_curriculum8k
```

`--max_iterations` 表示总目标。checkpoint 保存的是最后完成的索引，续训从下一轮开始，课程时钟恢复为“下一轮 × 24”。例如 `model_300.pt` 从 301/8000 开始，剩余 7699 次更新，最终保存 `model_7999.pt`。

模型与优化器状态会恢复；每个环境的地形等级没有保存在旧 checkpoint 中，因此重启后从低等级重新按表现升级，时间表的难度上限仍按恢复的迭代进度生效。训练必须 headless，启动前确认没有其他 Isaac Sim 实例。
