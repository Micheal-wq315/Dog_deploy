# Odin1 深度轮足 8000 轮课程

目标是先建立稳定低速控制，再学习带深度感知的地形通过，后期开放更高台阶、更陡坡面和更密集障碍。策略输入为1740维（本体/力矩68×3 + 深度8×16×12），输出16维；速度最终覆盖 x/y ±0.6 m/s、偏航 ±1 rad/s，姿态最终覆盖 pitch/roll ±10°、高度 ±7 cm。

配置入口为 `rp_wd_odin_depth_env_cfg.py`，训练入口为 `train_odin_depth.sh`。默认 256 个环境、8000 次 PPO 更新、每次更新 24 个策略步，所有时间表按这个 rollout 长度设计。

1740维 CNN 策略与旧780维 MLP checkpoint 架构不同，不能续训旧 checkpoint；新实验使用 `rp_wd_odin_depth_memory` 独立目录保存，避免误加载旧模型。

## 地形阶段

| 迭代范围 | 可用最高地形等级 | 目标 |
|---|---:|---|
| 0–1999 | 1 / 11 | 小台阶、缓坡和稀疏低箱体，先修正站姿并学稳定低速移动 |
| 2000–3999 | 2 / 11 | 提升移动方向与速度，熟悉上/下台阶和深度输入 |
| 4000–5999 | 4 / 11 | 扩展到完整速度范围，加入姿态/高度指令与推扰 |
| 6000–6999 | 6 / 11 | 提高台阶、坡度、粗糙度和箱体密度，在完整扰动下巩固 |
| 7000–7999 | 8 / 11 | 开放更高台阶和更密集障碍，做后期挑战 |

每个环境从第 0 级出生。走出半个地块（3 m）才升级，未完成预期距离的一半会降级；表格规定的是最高可用难度。能力不足的机器人会留在较低等级继续学习。第8级在7000轮解锁，避免把最后一级难度放在训练终点才开放。

地形生成 12 行 × 12 列，七类地形都有采样列。以下范围随地形行的 difficulty 变化：

| 地形 | 简单端 → 困难端 |
|---|---|
| 上/下台阶 | 1 → 12 cm，阶宽 40 cm |
| 随机方格 | 高差 1 → 10 cm |
| 坡面 | 坡度比 0 → 0.40（约 22°） |
| 平滑随机粗糙 | 振幅 ±0.5 → ±5.5 cm，30 cm 空间采样后平滑 |
| 随机箱体 | 1 → 8 个；可见高度约 4 → 22 cm，尺寸 25×25 → 65×55 cm |

高箱体主要用于学习绕行，台阶用于学习通过；最高几何难度是训练目标，尚无通过率结论。官方 uniform 随机高度场本身忽略 difficulty，本任务用 wrapper 显式缩放粗糙幅度。

## 同步增加的任务与扰动

| 项目 | 时间表 |
|---|---|
| 速度范围 | 前 200 轮为完整范围的 20%；200–3400 轮线性扩大至 x/y ±0.6 m/s、wz ±1 rad/s |
| 深度增强 | 前 500 轮清晰深度；500–2500 轮渐入 0.03 m 高斯噪声、1% 像素缺测与 80–100% 随机裁切；相机新帧推进8帧（约0.47秒）历史 |
| 姿态/高度 | 前 3000 轮目标为零；3000–5700 轮线性放大至 pitch/roll ±10°、高度 ±7 cm |
| 周期推扰 | 前 4000 轮不推；4000–6000 轮渐增至 x/y/z 速度扰动幅度 0.6/0.4/0.2 m/s，间隔 8–12 s |
| 力矩相关项 | 不设置电机力矩惩罚；12维腿部力矩反馈仍作为策略观测，保持部署接口不变 |

摩擦、质量、质心、执行器增益、关节参数与传感器偏置随机化沿用原 rough 配置。机身高度奖励和低高度终止都以机身正下方 RayCaster 命中的地面为参考，避免用地块出生原点估计当前支撑高度；滚动失配只对接触地面的轮子计算，减少抬轮越阶的错误惩罚。rough/Odin 的高度奖励分别为 0.8/1.0，误差核标准差为 0.10 m。

深度画面按传感器图像逆时针旋转90°，原始160×120横图变为120×160竖图，再按每格最近距离压到16行×12列；仿真深度采用光轴Z值，策略用CNN对8张网格图做空间编码。部署 adapter 的 `rotation_deg` 默认90，可传270切换方向；必须先用 `--save-depth` 对比原图、旋转图和网格，确认 Odin1 实物安装方向，并核对官方深度话题输出是光轴深度。训练观察 `Curriculum/terrain_levels`、`command_lin_vel`、`posture_command` 和 `push_curriculum`；同时检查实际速度误差、机身净空、回合长度和真实终止率，不能只根据平均回报判断能否通过地形。

需要注意：当前奖励是速度指令跟踪加碰撞/姿态约束，没有显式目标点或路径进度奖励；随机箱体用于提供可见障碍和接触反馈，尚不能据此保证形成稳定绕障规划。高箱体按绕行障碍设计，台阶通过能力必须用独立固定高度测试统计，不能只看训练回报或地形等级。

## 启动与续训

```bash
# 新训练，8000 轮总目标
./rl/scripts/train_odin_depth.sh --run_name odin1_no_torque_localheight_v1

# 从当前实验最近 checkpoint 继续，到总目标 8000
./rl/scripts/train_odin_depth.sh --resume --max_iterations 8000 --run_name odin1_no_torque_localheight_v1
```

`--max_iterations` 表示总目标。checkpoint 保存的是最后完成的索引，续训从下一轮开始，课程时钟恢复为“下一轮 × 24”。例如 `model_300.pt` 从 301/8000 开始，剩余 7699 次更新，最终保存 `model_7999.pt`。

模型与优化器状态会恢复；每个环境的地形等级没有保存在旧 checkpoint 中，因此重启后从低等级重新按表现升级，时间表的难度上限仍按恢复的迭代进度生效。训练必须 headless，启动前确认没有其他 Isaac Sim 实例。
