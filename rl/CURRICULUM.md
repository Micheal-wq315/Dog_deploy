# Odin1 轮足基础地形长期训练设计（v20，支持接续）

本版本先训练可靠运动和完整地形通过，再训练深度退化条件下的学生策略。推荐流程为 **18000轮基础地形PPO教师 → 三种子专项验收 → 2000轮在线动作蒸馏学生，共20000轮**；训练始终headless。v19在第2000/6000/12000轮安排阶段验收，失败立即停止后续训练；代码可运行不代表已得到可用模型。

## 输入、控制与训练边界

- 部署输入1740维：本体/腿部力矩68×3帧 + 深度8×16×12；输出16维。深度CNN与本体MLP保持单输入ONNX导出。
- 深度保留22张原始历史、每3帧抽取一张，共8通道，跨度约1.4秒（丢帧时更长）；最新图仍每个新相机帧更新，为后腿保留更长线索。
- 物理400Hz、策略50Hz、相机约15Hz；每次更新24个策略步。默认256环境，共约1.2288亿条环境转移；实际墙钟耗时需实测。
- 最终指令覆盖vx/vy ±0.6m/s、wz ±1rad/s；平地保留pitch/roll ±10°、高度±7cm控制。
- 12维腿部力矩仍按42N·m归一化作为观测；**不设置任何电机力矩惩罚**。ImplicitActuator力矩是PD估计，实机反馈差异仍需标定。
- 真实Odin1旋转方向、内参、外参及光轴深度语义尚未实测确认。当前90°逆时针校正、机身前上方位置与10°下俯均是待标定初值，启动长训练前应先采集实物数据。

## v17失败结论与v18修复依据

v17教师8000轮完成后，三种子固定基准每场景6次首次尝试：平地0/6、6cm上阶0/6、8cm下阶6/6但低接触0/6、12cm矮箱0/6。平地平均vx约0.133m/s，上阶约90%时间停滞；学生阶段未启动。末100轮平均地形等级约0.016，不能把训练日志66.3%的到点终止占比解读为台阶通过率。

1. 确认的重置错误：Isaac Lab在`command_manager.reset`之后才清零`episode_length_buf`。旧代码在`_resample_command`内检查步数为零，导致后续复位没有刷新终点、距离和碰撞峰值；跨地块后目标错误、碰撞峰值跨回合累计。v18覆盖指令`reset`，显式刷新这些状态，周期速度重采样不改变目标，并立即更新首帧指令。新增非零旧回合步数、部分/全量复位的回归。
2. 旧模型13环境短回放中四个KENN目标均为+1.09rad，实际约-0.83rad，PD估计力矩被裁到42N·m；这表明目标无效，不是应该提高电机限幅的证据。v18增加关节位置目标越限约束，没有新增力矩惩罚，也没有改1740→16接口。证据归档`rl/logs/evaluation/v18_diagnosis/old_policy_joint_targets.json`。
3. 加强台阶速度驱动，放松四轮着地、滚动失配、腿速和竖直运动约束；最低难度由连续四级改为单级。此处是基于失败现象的优化假设，效果待新模型验收确认。
4. 不续训失败教师。1000/3000轮加入阶段验收，及时发现慢走、顶限和卡阶，避免只看平均奖励跑满8000轮。评测CSV新增腿目标误差RMS、越限目标比例和PD估计饱和关节比例。

## 两阶段学习

| 阶段 | 任务后缀 | 迭代 | 学习目标与输入 | 日志实验 |
|---|---|---:|---|---|
| 教师 | `OdinDepth-Teacher-v0` | 18000 | PPO；同视野清晰深度历史＋本体感觉，学习站姿、运动和基础地形通过 | `rp_wd_odin_teacher` |
| 学生 | `OdinDepth-Student-v0` | 2000 | 从教师权重初始化；学生驱动仿真，在学生访问的状态上由清晰深度教师提供动作标签，使用Huber损失在线蒸馏 | `rp_wd_odin_student` |

教师和学生使用同一前向相机视野与8帧历史；教师没有完整高程图、背后地形或真实接触状态等额外actor输入。学生看退化深度，教师看对应的清晰深度。本版采用清晰深度教师，仍需要渲染相机；尚未实现廉价scandot教师、GRU门控或位姿补偿地图。

CNN把稀疏8帧作为通道输入，提供时间上下文；这不等于重建空间地图。背后落脚、长时间遮挡、快速转身仍是需要单独验证的边界。学生有意从教师初始化，避免随机策略先大量摔倒才获得有效标签。

## 专项赛道和指令

生成12个难度行、16个固定地形列，每块6×6m。平地4列（25%）、上阶4列（25%）、下阶4列（25%）、低障碍1列（6.25%）、起伏2列（12.5%）、缓坡1列（6.25%）。75%的环境直接用于平地和上下台阶；本轮不训练绕墙与交错绕障，避免基础运动与导航同时竞争。旧版13列综合地形配置仍保留在代码中，当前基础profile使用独立配方。

| 赛道 | 简单端→困难端 | 行为目标 |
|---|---|---|
| 上台阶 | 1→4级；每级1→8cm，踏面65→45cm | 依次抬轮、登上平台；最高累计升高32cm |
| 下台阶 | 同上，出生在上平台 | 稳定下降、控制落地冲击 |
| 矮障碍 | 两道横贯赛道的实体箱，高1→8cm、长30→50cm | 必须跨越，不把低台阶当成绕行墙 |
| 起伏 | 连续45cm长块，高差0→约5cm | 保持净空与滚动稳定性 |
| 坡道 | 2m长，上升4→50cm，坡度比0.02→0.25（约1.1→14°） | 连续上坡并进入顶端平台 |
| 平地 | 平面、任意出生朝向 | 前后/横向/转向、零指令、姿态和高度控制 |

台阶采用实体箱体垂直立面；不上插值高度场台阶，避免策略利用斜边。最低难度只有一级小台阶，随难度增加到连续四级。专项出生点在x=0.8m、朝+X（位置±6cm、yaw±0.1rad），终点在前方4.4m，容差35cm，回合最长30s。越界（左右偏移>2.6m或向后越过出生点45cm）终止，避免从相邻地块绕过跨越任务。

专项指令由“到终点的方向＋采样速度”转换成既有的机体系vx/vy/wz，策略不会额外接收目标坐标。速度重采样不改变终点。平地继续训练普通随机遥控指令；专项赛道固定零姿态/高度目标，让腿部自行适应台阶。部署时依然接收用户速度指令，不包含全局路径规划器。训练终点指令与实机人工指令有分布差异，必须分别用目标赛道和固定/键盘指令验证。

## 教师18000轮课程

| 教师迭代 | 最高地形等级（0–11） | 重点 |
|---|---:|---|
| 0–1999 | 0 | 站姿、速度跟踪、单级约1cm台阶 |
| 2000–4999 | 2 | 约1–3cm单级/双级台阶，低障碍与缓坡 |
| 5000–8999 | 5 | 约3–4.5cm连续台阶与起伏，长期巩固 |
| 9000–12999 | 8 | 约4.5–6.3cm连续台阶与稳定下阶 |
| 13000–17999 | 11 | 逐步覆盖6–8cm四级台阶，保留5000轮最高难度上限训练 |

这是难度上限；几何参数按难度行内随机采样，并非某轮直接切换到表中最大高度。**到达终点、未触发真实失败、且整回合非足端合力峰值<120N才升级**；失败或超时降级，到点但严重撞击则保持。平地固定0级，侧滑、摔远或跨相邻地块均不构成成功。

专项环境中固定四分之一（env_id每4个取1个）最高等级保持2，其余环境按完整上限升级，长期保留简单地形复习。这些复习环境仍必须成功才升级，不会在复位时随机跳到更难地形。学生同样保留该机制。

- 速度/偏航：前2000轮为最终范围60%（vx/vy ±0.36m/s）；2000–10000轮扩展至vx/vy ±0.6m/s、wz ±1rad/s。专项采样当前vx正向上限的60–100%。
- 平地姿态/高度：前14000轮为零，14000–17000轮扩展至±10°、±7cm；专项始终零目标。
- 小幅推扰：前15000轮为零，15000–18000轮渐入x±0.15、y±0.10m/s，z为零，间隔8–12s。
- 摩擦、质量、质心、执行器增益、关节摩擦/电枢、IMU与编码器偏置沿用rough随机化。
- 教师使用清晰深度，保留本体噪声与物理随机化；延续v18奖励和位置目标越限约束，不增加力矩惩罚。输入/动作、深度历史、PD和电机限幅均保持不变。

## 学生2000轮课程与深度随机化

学生一开始使用完整速度/姿态范围，几何上限11级；每个环境仍从0级开始，达到安全通过条件才升级。深度增强在前1000轮由零渐增到目标强度，后1000轮巩固；推扰在500–1000轮渐入。

| 增强 | 目标配置 | 时间一致性 |
|---|---|---|
| 高斯深度噪声 | 池化后标准差3cm | 每张新相机帧采样，避免最小池化放大像素极值 |
| 独立像素缺测 | 原图1% | 无回波沿用部署语义，填最远距离 |
| 几何裁切 | 保留95–100%视野 | 每回合固定裁切与偏移，逐步渐入，避免逐帧随机缩放破坏时间关系 |
| 深度常值/尺度误差 | ±4cm、±2% | 每回合固定；偏差与严重退化档启用 |
| 连片遮挡 | 严重档每新帧30%概率出现5×5网格遮挡 | 严重档占10%回合，因此全体约3%的帧出现该遮挡 |
| 数据包丢失 | 每新帧8% | 保持整段历史，不把旧图伪装成新图重复推进 |
| 延迟 | 每回合0–2相机帧，约0–133ms | 从真实新帧队列取延迟帧 |

回合质量档初始分布为正常60%、带偏差30%、严重退化10%，参考公开工作的分档训练思想；这是待真实Odin1数据调整的工程初值，不能直接视为相机实测噪声。每个策略步重复读同一图像不会重新采样增强，也不会推进深度记忆。单环境复位会清除该环境历史和延迟队列，首帧复制填满，其他环境不受影响。

无回波仍编码为最远距离，因此当前接口没有独立的未知/置信度通道；长时间整幅缺测与空旷空间可能混淆。部署端超时保护仍必须有效；本版不声称解决完整感知失效下的安全导航。

## 奖励与运动约束

| 项目 | 权重/规则 | 作用 |
|---|---|---|
| 缩短终点距离 | +3，按实际距离变化/指令速度归一化，截断[-1,1] | 给跨越、绕行提供真实进度梯度，停车没有进度奖励 |
| 安全到点 | +5/次（RewardManager权重250×dt=0.02） | 进入35cm容差、倾角<25°、净空>27cm且未同时失败才奖励成功；成功作为正常终态，不做超时bootstrap |
| 速度跟踪 | 3.0；仅绕墙列乘0.35，其余全额；std=0.25m/s | 加强运动驱动，停止削弱所有台阶赛道的跟踪 |
| 偏航跟踪 | 1.0；专项乘0.5，平地全额 | 允许绕行时临时偏离直接朝向终点的指令 |
| 高度跟踪 | +1.0，std=8cm，本地地面基准 | 抑制长期趴低、半立运动 |
| 姿态跟踪 | +0.3；平地俯仰/横滚10°，专项俯仰20°、横滚10°后软惩罚 | 允许跨阶短时抬头，保留侧倾控制 |
| 非足端冲击 | -1.0×clip((峰值-20N)/100N,0,1) | 抑制机身与腿部撞击，有界，不压制正常足端支撑 |
| 轮端冲击 | -0.5×clip((峰值-180N)/180N,0,1) | 抑制下阶“直接摔落”的高冲击解 |
| 滚动失配 | 平地-2.5，专项-0.5，只统计接触轮 | 保留正常滚动，允许暂时抬轮 |
| 四轮接触/腿速 | 平地+0.3 / -5e-4；专项0 / -5e-5 | 减轻跨台阶时的四轮着地和抬轮矛盾 |
| 无效位置目标 | -5×腿关节目标越过物理限位的平方均值 | 避免小腿长期顶限；不改变动作缩放或42N·m限幅 |
| 其他约束 | 动作率-0.002、竖直速度-0.2、关节加速度/限位、非足端接触、真实失败惩罚 | 沿用控制平顺与安全限制；最低净空22cm |
| 力矩惩罚 | 无 | 腿部力矩只作为输入 |

接触传感器保存8个物理子步，覆盖完整20ms策略间隔，减少台阶冲击漏采。上述接触阈值是初始标定值，需要根据质量、足端力分布与实物冲击数据调整。

## 启动、续训和评测

2026-10-30续训说明：v19已完成教师2000轮，固定平地评测0/2完成、平均vx约0.0042m/s，因此原流程按阶段门槛停止。按用户继续长期训练的要求，可使用`--resume-teacher-checkpoint <model_1999.pt>`从第2000轮接续至6000/12000/18000，保留优化器和课程时钟，不重跑已完成阶段。再加`--continue-on-stage-failure`时，完整评测给出的中期性能不达标只记录诊断；训练异常、评测异常或缺失结果仍停止，最终18000轮教师资格验收不受该开关影响。总目标仍为累计18000教师＋2000学生，并非另外增加20000轮。此模式延长学习机会，不代表当前模型已具备基础通过能力。


```bash
# 完整流程：18000教师→三种子验收达标→2000学生，合计20000；同一时间只有一个Sim
./rl/scripts/train_odin_pipeline.sh --num_envs 256 --seed 42

# 分阶段启动（教师完成后再运行学生）
./rl/scripts/train_odin_depth.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Teacher-v0 --num_envs 256 --run_name basic_v19
./rl/scripts/train_odin_depth.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Student-v0 --num_envs 256 \
  --teacher_checkpoint rl/logs/rsl_rl/rp_wd_odin_teacher/<run>/model_17999.pt --run_name basic_v19

# 学生中断后续训；max_iterations为本阶段总目标
./rl/scripts/train_odin_depth.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Student-v0 \
  --resume --load_run <学生run名> --max_iterations 2000

# 固定障碍基准，学生与教师checkpoint都可加载
./rl/scripts/gui_test.sh --obstacle-benchmark --headless \
  --checkpoint rl/logs/rsl_rl/rp_wd_odin_student/<run>/model_1999.pt \
  --seed 42 --save-dir rl/logs/evaluation/basic_v19_seed42 --save-depth --export

# 键盘控制，指定深度Play任务
./rl/scripts/teleop.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Play-v0 \
  --checkpoint rl/logs/rsl_rl/rp_wd_odin_student/<run>/model_1999.pt --num_envs 1 --teleop-scale 0.5
```

一键脚本从头启动新教师，保留原v18实验和checkpoint。目标按累计迭代2000→6000→12000→18000分段；各段恢复优化器与课程时钟，学生另训2000轮，总目标20000轮：

- 2000/6000轮：运行固定六场景评测，平地作为硬门槛，上下阶暂只记录诊断。避免在尚未训练到相应高度时强求最高台阶通过。
- 12000轮：平地、6cm上阶和8cm下阶作为阶段门槛。
- 18000轮：种子42/43/44各12环境；平地、6cm上阶、8cm下阶共每场景6次首次尝试，完成率≥80%、低接触完成率≥60%，且平地0.35m/s指令下平均vx≥0.25m/s，才进入2000轮学生蒸馏。
- 12cm矮箱、45cm墙与交错障碍保留测试结果，不作为本轮1–8cm基础训练的资格门槛，不能据此宣称已具备12cm跨越或绕障能力。

阶段或最终门槛失败时停止后续流程并保存结果；因此20000是训练目标，不保证失败教师也会进入学生阶段。各段只接受本次完整训练的`training_result.json`和最终checkpoint；资格结果保存在`stage_gate.json`或`qualification.json`。评测、续训和蒸馏始终串行，同一时刻只有一个Sim。独立的`OdinDepth-v0`直接PPO对照同步为20000轮，课程与教师一致，另含深度增强。

旧780维模型不能用于新CNN；既有1740维CNN可以作为回放对照，v14/v15连续历史模型需给test/play传`--depth-memory-stride 1`，ROS adapter传`memory_stride:=1`；v16及以后默认3，时序语义不同，新训练应另开实验。学生checkpoint可直接由test/play读取并导出单输入1740→16 ONNX，不加载教师到部署端。续训恢复本阶段迭代时钟；每环境地形等级没有保存在checkpoint中，复位后重新从低级按表现升级。

固定基准含平地、6cm上阶、8cm下阶、12cm矮箱、45cm墙和交错障碍。默认0.35m/s运行1000步（20s），给4m交错赛道留足时间。统计逐环境逐回合完成数、完成比例、低接触完成比例、停滞比例、非足端接触比例和轮端力P95。不同场景通过距离阈值为3.0/3.2/2.0/2.3/2.8/4.0m，且要求回到中心±0.7m、终点净空≥30cm且倾角≤25°；不会把仅靠近障碍1.5m或趴低越过终点当成成功。测试时间耗尽但未完成的尾回合单独记录，多个失败回合不拼成一条成功轨迹。

地形仍合并为单一mesh，非足端接触不能精确区分“障碍”和“地面”；低接触完成率是接触传感器定义的指标，不是精确障碍碰撞率。验收至少比较种子42/43/44，分别检查清晰输入、退化输入、定向目标和人工速度指令；同步保存深度图、轨迹与接触数据。低台阶通过率和横移精度合格后再评估困难端，不以平均奖励替代实测。
