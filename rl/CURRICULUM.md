# Odin1 轮足地形与近场绕障训练设计（v17）

本版本先训练可靠运动和完整地形通过，再训练深度退化条件下的学生策略。推荐流程为 **8000轮清晰深度PPO教师 → 三种子专项验收 → 2000轮在线动作蒸馏学生，共10000轮**；训练始终headless。代码已接入，不代表已得到可用的新模型，实际通过率需要训练后固定评测。

## 输入、控制与训练边界

- 部署输入1740维：本体/腿部力矩68×3帧 + 深度8×16×12；输出16维。深度CNN与本体MLP保持单输入ONNX导出。
- 深度保留22张原始历史、每3帧抽取一张，共8通道，跨度约1.4秒（丢帧时更长）；最新图仍每个新相机帧更新，为后腿保留更长线索。
- 物理400Hz、策略50Hz、相机约15Hz；每次更新24个策略步。默认256环境，共约6144万条环境转移；实际墙钟耗时需实测。
- 最终指令覆盖vx/vy ±0.6m/s、wz ±1rad/s；平地保留pitch/roll ±10°、高度±7cm控制。
- 12维腿部力矩仍按42N·m归一化作为观测；**不设置任何电机力矩惩罚**。ImplicitActuator力矩是PD估计，实机反馈差异仍需标定。
- 真实Odin1旋转方向、内参、外参及光轴深度语义尚未实测确认。当前90°逆时针校正、机身前上方位置与10°下俯均是待标定初值，启动长训练前应先采集实物数据。

## 两阶段学习

| 阶段 | 任务后缀 | 迭代 | 学习目标与输入 | 日志实验 |
|---|---|---:|---|---|
| 教师 | `OdinDepth-Teacher-v0` | 8000 | PPO；同视野清晰深度历史＋本体感觉，学习站姿、运动、上下阶和绕行 | `rp_wd_odin_teacher` |
| 学生 | `OdinDepth-Student-v0` | 2000 | 从教师权重初始化；学生驱动仿真，在学生访问的状态上由清晰深度教师提供动作标签，使用Huber损失在线蒸馏 | `rp_wd_odin_student` |

教师和学生使用同一前向相机视野与8帧历史；教师没有完整高程图、背后地形或真实接触状态等额外actor输入。学生看退化深度，教师看对应的清晰深度。本版采用清晰深度教师，仍需要渲染相机；尚未实现廉价scandot教师、GRU门控或位姿补偿地图。

CNN把稀疏8帧作为通道输入，提供时间上下文；这不等于重建空间地图。背后落脚、长时间遮挡、快速转身仍是需要单独验证的边界。学生有意从教师初始化，避免随机策略先大量摔倒才获得有效标签。

## 专项赛道和指令

生成12个难度行、13个固定地形列，每块6×6m。平地3列用于完整随机速度及姿态控制；其余10列采用前方终点任务。上下台阶各3列，合计占46.2%；平地占23.1%；矮障碍、绕行、起伏和坡道各占7.7%。

| 赛道 | 简单端→困难端 | 行为目标 |
|---|---|---|
| 上台阶 | 4级；每级1→12cm，踏面50→38cm | 依次抬轮、登上平台；最高累计升高48cm |
| 下台阶 | 同上，出生在上平台 | 稳定下降、控制落地冲击 |
| 矮障碍 | 两道横贯赛道的实体箱，高1→12cm、长30→50cm | 必须跨越，不把低台阶当成绕行墙 |
| 绕行墙 | 固定高45cm，宽70→300cm，中心左右随机±25cm | 两侧绕行，再回到终点；不是跨越任务 |
| 起伏 | 连续45cm长块，高差0→约7cm | 保持净空与滚动稳定性 |
| 坡道 | 2m长，上升4→50cm，坡度比0.02→0.25（约1.1→14°） | 连续上坡并进入顶端平台 |
| 平地 | 平面、任意出生朝向 | 前后/横向/转向、零指令、姿态和高度控制 |

台阶采用实体箱体垂直立面；不上插值高度场台阶，避免策略利用斜边。专项出生点在x=0.8m、朝+X（位置±6cm、yaw±0.1rad），终点在前方4.4m，容差35cm，回合最长30s。越界（左右偏移>2.6m或向后越过出生点45cm）终止，避免从相邻地块绕过跨越任务。

专项指令由“到终点的方向＋采样速度”转换成既有的机体系vx/vy/wz，策略不会额外接收目标坐标。速度重采样不改变终点。平地继续训练普通随机遥控指令；专项赛道固定零姿态/高度目标，让腿部自行适应台阶。部署时依然接收用户速度指令，不包含全局路径规划器。训练终点指令与实机人工指令有分布差异，必须分别用目标赛道和固定/键盘指令验证。

## 教师8000轮课程

| 教师迭代 | 最高地形等级（0–11） | 重点 |
|---|---:|---|
| 0–999 | 0 | 低速站稳、小台阶、矮障碍和窄墙绕行 |
| 1000–2499 | 2 | 巩固完整4级台阶，扩大速度范围 |
| 2500–3999 | 5 | 增大台阶和墙宽，加入平地姿态/高度任务 |
| 4000–4499 | 8 | 更高台阶与起伏，开始小幅推扰 |
| 4500–7999 | 11 | 解锁全部几何难度，保留3500轮巩固 |

表格仅解锁难度上限。**到达终点、未触发真实失败、且整回合非足端合力峰值<120N才升级**；未到点失败或超时降级；到点但发生严重撞击保持当前等级。平地列固定0级。距离由真实根部位置计算，侧滑远离起点、摔出距离、跨相邻地块均不构成成功。

- 速度/偏航范围：前500轮为最终范围40%，500–3000轮线性扩展至全范围。专项速度采样为当前vx正向上限的60–100%，平地指令正负均覆盖。
- 平地姿态/高度：前3000轮为零，3000–5000轮扩展到±10°和±7cm；专项始终零目标。
- 推扰：前4000轮为零，4000–5500轮增加至x±0.25、y±0.20m/s，z为零，间隔8–12s。
- 摩擦、质量、质心、执行器增益、关节摩擦/电枢、IMU与编码器偏置沿用rough随机化。
- 教师使用清晰深度，保留本体噪声和物理随机化。PPO折扣gamma=0.995，让绕墙后恢复前进的收益能传播得更远。

## 学生2000轮课程与深度随机化

学生一开始使用完整速度/姿态范围，几何上限11级；每个环境仍从0级开始，达到安全通过条件才升级。深度增强在前1000轮由零渐增到目标强度，后1000轮巩固；推扰在500–1000轮渐入。

| 增强 | 目标配置 | 时间一致性 |
|---|---|---|
| 高斯深度噪声 | 池化后标准差3cm | 每张新相机帧采样，避免最小池化放大像素极值 |
| 独立像素缺测 | 原图1% | 无回波沿用部署语义，填最远距离 |
| 几何裁切 | 保留95–100%视野 | 每回合固定裁切与偏移，逐步渐入，避免逐帧随机缩放破坏时间关系 |
| 深度常值/尺度误差 | ±4cm、±2% | 每回合固定；偏差与严重退化档启用 |
| 连片遮挡 | 严重档每新帧30%概率出现5×5网格遮挡 | 严重档占10%回合，因此全体约3%的帧出现该遮挡 |
| 数据包丢失 | 每新帧8% | 保持整段历史，不把旧图伪装成新图重复推进 |
| 延迟 | 每回合0–2相机帧，约0–133ms | 从真实新帧队列取延迟帧 |

回合质量档初始分布为正常60%、带偏差30%、严重退化10%，参考公开工作的分档训练思想；这是待真实Odin1数据调整的工程初值，不能直接视为相机实测噪声。每个策略步重复读同一图像不会重新采样增强，也不会推进深度记忆。单环境复位会清除该环境历史和延迟队列，首帧复制填满，其他环境不受影响。

无回波仍编码为最远距离，因此当前接口没有独立的未知/置信度通道；长时间整幅缺测与空旷空间可能混淆。部署端超时保护仍必须有效；本版不声称解决完整感知失效下的安全导航。

## 奖励与运动约束

| 项目 | 权重/规则 | 作用 |
|---|---|---|
| 缩短终点距离 | +2，按实际距离变化/指令速度归一化，截断[-1,1] | 给跨越、绕行提供真实进度梯度，停车没有进度奖励 |
| 安全到点 | +5/次（RewardManager权重250×dt=0.02） | 进入35cm容差、倾角<25°、净空>27cm且未同时失败才奖励成功；成功作为正常终态，不做超时bootstrap |
| 速度跟踪 | 1.5；专项乘0.35，平地全额；std=0.35m/s | 给临时侧向绕行让出空间 |
| 偏航跟踪 | 1.0；专项乘0.5，平地全额 | 允许绕行时临时偏离直接朝向终点的指令 |
| 高度跟踪 | +1.0，std=8cm，本地地面基准 | 抑制长期趴低、半立运动 |
| 姿态跟踪 | +0.3；超过约10°的倾斜仍有软惩罚 | 保持控制能力，同时允许跨阶所需的短时姿态变化 |
| 非足端冲击 | -1.0×clip((峰值-20N)/100N,0,1) | 抑制机身与腿部撞击，有界，不压制正常足端支撑 |
| 轮端冲击 | -0.5×clip((峰值-180N)/180N,0,1) | 抑制下阶“直接摔落”的高冲击解 |
| 滚动失配 | 平地-10，专项-2.5，只统计接触轮 | 保留正常滚动，允许暂时抬轮 |
| 四轮接触/腿速 | 平地+1 / -5e-4；专项+0.1 / -2e-4 | 减轻跨台阶时的四轮着地和抬轮矛盾 |
| 其他约束 | 动作率、关节加速度/限位、非足端接触、真实失败惩罚 | 沿用控制平顺与安全限制；最低净空22cm |
| 力矩惩罚 | 无 | 腿部力矩只作为输入 |

接触传感器保存8个物理子步，覆盖完整20ms策略间隔，减少台阶冲击漏采。上述接触阈值是初始标定值，需要根据质量、足端力分布与实物冲击数据调整。

## 启动、续训和评测

```bash
# 完整流程：8000教师→三种子验收达标→2000学生，合计10000；同一时间只有一个Sim
./rl/scripts/train_odin_pipeline.sh --num_envs 256 --seed 42

# 分阶段启动（教师完成后再运行学生）
./rl/scripts/train_odin_depth.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Teacher-v0 --num_envs 256 --run_name course_v17
./rl/scripts/train_odin_depth.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Student-v0 --num_envs 256 \
  --teacher_checkpoint rl/logs/rsl_rl/rp_wd_odin_teacher/<run>/model_7999.pt --run_name course_v17

# 学生中断后续训；max_iterations为本阶段总目标
./rl/scripts/train_odin_depth.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Student-v0 \
  --resume --load_run <学生run名> --max_iterations 2000

# 固定障碍基准，学生与教师checkpoint都可加载
./rl/scripts/gui_test.sh --obstacle-benchmark --headless \
  --checkpoint rl/logs/rsl_rl/rp_wd_odin_student/<run>/model_1999.pt \
  --seed 42 --save-dir rl/logs/evaluation/course_v17_seed42 --save-depth --export

# 键盘控制，指定深度Play任务
./rl/scripts/teleop.sh --task Isaac-Velocity-Rough-RPWD-OdinDepth-Play-v0 \
  --checkpoint rl/logs/rsl_rl/rp_wd_odin_student/<run>/model_1999.pt --num_envs 1 --teleop-scale 0.5
```

一键脚本只接受本次完整教师训练的`training_result.json`和最终模型。教师结束后顺序跑种子42/43/44、每种子12环境的固定基准；平地、上阶、下阶、矮障碍各有6次首次尝试，要求完成率≥80%且低接触完成率≥60%，任一未达标停止学生阶段。只考察每个环境的首次尝试，避免通过后的再次摔倒与尾回合扭曲门槛；墙与交错障碍保留诊断，不作为台阶教师晋级门槛。资格结果保存为`qualification.json`。教师训练或验收失败立即停止；不会拿旧模型继续学生阶段。新教师从头训练，不续训旧奖励/旧赛道实验。仍保留原`OdinDepth-v0`直接PPO作为10000轮对照，日志写入`rp_wd_odin_course`；其上限在0/1000/3000/5000/6000轮解锁0/2/5/8/11，其余速度/姿态/推扰时间表同上，深度增强500–2500轮渐入。

旧780维模型不能用于新CNN；既有1740维CNN可以作为回放对照，v14/v15连续历史模型需给test/play传`--depth-memory-stride 1`，ROS adapter传`memory_stride:=1`；v16及以后默认3，时序语义不同，新训练应另开实验。学生checkpoint可直接由test/play读取并导出单输入1740→16 ONNX，不加载教师到部署端。续训恢复本阶段迭代时钟；每环境地形等级没有保存在checkpoint中，复位后重新从低级按表现升级。

固定基准含平地、6cm上阶、8cm下阶、12cm矮箱、45cm墙和交错障碍。默认0.35m/s运行1000步（20s），给4m交错赛道留足时间。统计逐环境逐回合完成数、完成比例、低接触完成比例、停滞比例、非足端接触比例和轮端力P95。不同场景通过距离阈值为3.0/3.2/2.0/2.3/2.8/4.0m，且要求回到中心±0.7m、终点净空≥30cm且倾角≤25°；不会把仅靠近障碍1.5m或趴低越过终点当成成功。测试时间耗尽但未完成的尾回合单独记录，多个失败回合不拼成一条成功轨迹。

地形仍合并为单一mesh，非足端接触不能精确区分“障碍”和“地面”；低接触完成率是接触传感器定义的指标，不是精确障碍碰撞率。验收至少比较种子42/43/44，分别检查清晰输入、退化输入、定向目标和人工速度指令；同步保存深度图、轨迹与接触数据。低台阶通过率和横移精度合格后再评估困难端，不以平均奖励替代实测。

## 参考与取舍

- [Agarwal等，CoRL 2022](https://proceedings.mlr.press/v205/agarwal23a/agarwal23a.pdf)：两阶段教师/学生、DAgger、前向视野需要历史；项目明确报告后腿记忆错误、看不到落差及盲走下阶的高冲击失败。本版采用同视野清晰教师和含噪学生，尚未实现scandot加速与GRU。
- [Miki等，2022](https://arxiv.org/abs/2201.08117)：传感器质量分档、持续偏差、视觉/本体融合，以及台阶碰撞几何漏洞。本版落实质量分档、连贯增强、实体台阶和接触约束；注意力门控、真实位姿补偿与完整地图仍为后续架构方案。
