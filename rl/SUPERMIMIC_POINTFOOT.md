# 点足版 SuperMimic 训练设计

## 目标与分支

本方案在独立分支 codex/pointfoot-supermimic-wm 中，把 go2w-supermimic 的模型式训练主线迁移到 RP_wd 固定点脚模型。目标是让四个无电机球脚主动抬过台阶、踩到更高踏面，再逐级提高台阶；模型仍只用12个腿部主动关节，不混入轮足执行器。

这是算法迁移，不是直接复用 Go2W 的二进制权重或 MuJoCo 代码。Go2W 项目使用 mjlab/MuJoCo 和轮速动作，当前仓库使用 Isaac Lab/PhysX 和12维关节位置动作，动力学状态、执行器和仿真接口都不同。迁移的是其训练循环、地形特权、残差世界模型、想象轨迹反传、事件采样和成功率课程。

## 观测与训练角色

| 部件 | 输入 | 训练/部署职责 |
|---|---:|---|
| Actor | 本体历史135维 | 3帧×45维；陀螺仪、投影重力、速度指令、12关节位置/速度、上一动作。Actor 不接触高度图，是盲策略 |
| Critic | 330维 | 34维真值机身状态、3维命令、12维上一动作、273维前视高度图、4脚接触、4脚法向载荷 |
| World Model | 334维 | 34维物理状态、当前/上一动作、3维速度命令、273维高度扫描 |
| World Model 输出 | 连续315维＋事件6维 | 状态残差34、平面位姿变化3、扫描残差273、四脚载荷4、奖励1；另预测四脚接触、非脚碰撞和回合终止 |
| Actor 动作 | 12维 | tanh 限制到[-1,1]；点足任务专用缩放为ABAD 0.125、HIP 0.6、KENN 0.8rad，参考Go2W上阶版的大髋/膝活动幅值；四个固定球脚没有动作输出 |

高度图是以 base_link 为参考的21×13扫描，分辨率0.1m，总计273点，扫描窗口约2.0×1.2m并向机器人前方偏移。它只进入世界模型和 Critic，不拼进 Actor 的135维输入。训练器因此是在特权训练后形成盲式本体策略；本版本没有 Odin1 深度相机，也没有视觉学生蒸馏阶段。

34维状态顺序为：机身离地净空1、投影重力3、机体线速度3、机体角速度3、12关节相对位置、12关节速度。位姿增量用上一步机体朝向表达，符合 Go2W 世界模型的局部位移预测方式。

## 上阶地形与课程

- 楼梯沿世界局部 +X 定向，机器人出生在第一级前约1.5m；每个赛道有五级连续台阶、踏面0.30m。课程行与单级高度一一对应为2、4、8、12、16、20cm，地形生成器的行内随机数不会串到相邻高度级。
- 地形生成器有6行、4列：1列平地、2列上阶、1列轻度随机粗糙地；所有环境从最低难度开始。平地与粗糙地用于保持基本行走能力，上阶占一半地形列。
- 上阶命令每回合固定，vx 0.20–0.45m/s，vy ±0.05m/s，wz ±0.08rad/s；重置时朝向仅在±0.08rad内随机，避免机器人背对楼梯或临近台阶突然换向。
- 升级需要当前楼梯等级累计64个有效回合，最近64回合通过率至少60%，并满足阶段最少训练步数。未通过的回合会留在原级或退一级；走得远但摔倒、侧出赛道、没有稳定到达顶层都不算上阶成功。
- 楼梯通过条件检查前进距离、横向赛道范围、最终机身高度与该级总高度一致，以及机身仍稳定。阶段最早开放步数为0、3000、8000、15000、22000、30000。

这些高度和成功率门槛沿用 Go2W 的分级思路；当前点足几何和站立高度已按本仓库 URDF 配置，不照搬 Go2W 的机器人参数。

## 抬脚与落地信号

基线点足任务原先只有一般腾空时间和脚滑惩罚，且地形是中心向外的金字塔台阶，机器人出生后不一定朝上阶方向行走。新任务使用清楚朝前的楼梯，并加入三类信号：

1. 前方射线发现更高踏面时，对摆动脚接近目标净空的高斯得分增量奖励；每次摆动只累计到达过的最高得分，因此抬到位后悬脚不会持续刷分。平地没有高踏面时不奖励空摆腿。
2. 脚端从离地转为接触，且支撑面相对上次着地点升高时，给一次落到更高踏面的事件奖励。
3. 只对朝前的楼梯进度给有界奖励，配合原有速度跟踪项；机身倾斜和垂向运动惩罚降低，避免奖励与真实跨阶动作互相抵消。

当前权重为 stair_lift=6.0、stair_landing=10.0、stair_progress=0.5；抬腿以目标高度高斯核的单摆动增量计分，着陆按接触变化事件计分。未增加电机力矩惩罚。碰撞头学习非脚碰撞标签，原有非脚接触惩罚与跌倒终止也保留。

## SuperMimic 更新循环

每次更新默认先执行一个真实仿真策略步，与 Go2W 的单步采集节奏对齐：

1. 使用带 OU 过程噪声的 Actor 在 Isaac Lab 里采集真实状态、奖励、地形扫描、足端接触和载荷。
2. 将512个策略步的GPU回放池用于训练世界模型；每个批次窗口长度8，连续学习2次。约四分之一批次从接触变化、碰撞、大脚端载荷或终止附近抽取，提高稀有跨阶样本利用率。
3. 世界模型拟合下一状态/扫描残差、机身位姿变化、真实奖励、足端接触和载荷、非脚碰撞及终止概率；序列跨过回合终止时会截断，防止把自动重置后的状态串到旧回合。
4. 冻结世界模型参数但保留对动作输入的梯度，进行32步想象；Actor 最大化折扣回报，特权 Critic 用TD(λ)目标并按5轮、4个小批次训练。世界模型每次采样更新4次。模型与Actor/Critic均使用梯度裁剪。

默认配置：64环境、总目标40000次更新、世界模型隐藏层512×3、Actor/Critic隐藏层256/128/64、warmup 300采样步、折扣0.99、λ=0.95。Go2W v7 训练脚本的世界模型/想象更新流程、32步想象、Actor学习率渐进升起及前20000轮保持初始衰减阶段都已迁移；批次按Isaac Lab默认64环境缩放（没有照抄MuJoCo Warp的4096环境/8192想象批次）。checkpoint保存网络、优化器和地形课程状态；恢复时回放池重新采样，避免保存大量仿真转移数据。

与旧的 wheel SuperMimic 程序不同，点足训练器仅有一个状态模型、一个盲Actor和一个特权Critic；没有轮速/轮力输入、Odin深度学生或16维轮足动作。当前没有将策略导出到 ROS 点足部署节点，因为部署端尚无对应的12维点足推理配置。

## 启动与查看

在此分支仓库根目录运行：

~~~bash
./rl/scripts/train_pointfoot_supermimic.sh --num_envs 64 \
  --iterations 40000 --seed 42 --run_name 大狗点足版
~~~

续训示例：

~~~bash
./rl/scripts/train_pointfoot_supermimic.sh --num_envs 64 \
  --iterations 40000 --seed 42 \
  --resume rl/logs/pointfoot_supermimic/<运行目录>/teacher_latest.pt
~~~

训练完成或停止后，用 GUI 回放：

~~~bash
./rl/scripts/play_pointfoot_supermimic.sh \
  --checkpoint rl/logs/pointfoot_supermimic/<运行目录>/teacher_latest.pt \
  --num_envs 1
~~~

训练日志为运行目录下的 metrics.jsonl；除总回报与课程等级外，每50轮还记录加权奖励分项/秒（包含 stair_lift、stair_landing、stair_progress），便于判断狗是否真的开始主动抬脚和踩上踏面。checkpoint每1000轮保存一次。默认脚本强制 headless、检查是否已有 Isaac Sim，并用 systemd-inhibit 阻止休眠。训练、GUI回放与其它仿真任务必须串行运行。

## 当前验证状态与边界

代码已实现，静态语法与无仿真契约检查按版本记录执行；本版本没有启动 Isaac Sim、没有启动训练，也没有生成策略 checkpoint。因此楼梯几何、奖励事件时序、Isaac Lab任务初始化和实际爬阶能力尚未获得仿真运行验证；不能据此宣称训练效果已改善。

此训练器的策略是135维输入、12维输出，和轮足部署端的168/1740维输入、16维输出都不兼容。部署前必须另建点足推理动作配置和模型导出/评测链路。训练流程启用前应先跑一次1–2轮、4–8环境的 headless 初始化冒烟，确认射线尺寸、接触刚体名称、奖励事件和地形课程工作正常。
